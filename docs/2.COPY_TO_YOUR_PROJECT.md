# Copy to Your Project Guide

This guide helps you copy the timezone handling code to your own projects.

---

## 🎯 What You Can Copy

All utilities, hooks, and components are designed to be **completely portable** - they have no dependencies on this specific app.

---

## 📦 Step 1: Install Dependencies

```bash
npm install date-fns date-fns-tz
# or
yarn add date-fns date-fns-tz
# or
pnpm add date-fns date-fns-tz
```

---

## 📋 Step 2: Copy Files

### Option A: Copy Everything (Recommended for Learning)

Copy these folders to your project:

```
src/utils/
  ├── timezone.ts          ✓ Copy
  └── dateValidation.ts    ✓ Copy

src/hooks/
  ├── useTimezone.ts       ✓ Copy
  ├── useDateTimeConverter.ts  ✓ Copy
  └── useEvents.ts         ⚠️  Modify for your API

src/types/
  └── event.ts             ⚠️  Adapt to your data model
```

### Option B: Copy Only What You Need

#### Minimal Setup (Just Timezone Conversion)

1. Copy: `src/utils/timezone.ts`
2. Use the functions directly

```typescript
import {
  getUserTimezone,
  convertToUTC,
  formatEventDateTime
} from "@/utils/timezone";

// Detect timezone
const timezone = getUserTimezone();

// Convert to UTC for storage
const utc = convertToUTC("2025-01-15T10:00", timezone);

// Format for display
const display = formatEventDateTime(utc, timezone);
```

#### With React Hooks

1. Copy: `src/utils/timezone.ts`
2. Copy: `src/hooks/useTimezone.ts`
3. Copy: `src/hooks/useDateTimeConverter.ts`

```typescript

import { useDateTimeConverter } from "@/hooks/useDateTimeConverter";

function MyComponent() {
  const { timezone } = useTimezone();
  const { formatDateTime } = useDateTimeConverter();

```

## ⚠️ Common Mistakes to Avoid

### Mistake 1: Forgetting to Convert to UTC
```typescript
// ❌ BAD
await db.save({ startDateTime: userInput }); // Local time!

// ✅ GOOD
const utc = convertToUTC(userInput, timezone);
await db.save({ startDateTime: utc });
```

### Mistake 2: Not Attaching Timezone
```typescript
// ❌ BAD
<input type="datetime-local" onChange={handleChange} />
// How do you know what timezone this is in?

// ✅ GOOD
const timezone = getUserTimezone();
// Now you can convert correctly
```

### Mistake 3: Converting on Display Incorrectly
```typescript
// ❌ BAD
new Date(utcString).toLocaleString(); // Uses system locale, unreliable

// ✅ GOOD
formatInTimeZone(utcString, timezone, 'PPP p');
```
